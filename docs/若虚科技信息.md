## 五、命名与范围说明（内部参考，不作为官网正文）

- 中文简称、英文导航及完整英文名称以服务体系概览表为准，五类名称已由用户确认。
- AI Infra、FDE、RAG、Agent 和 AIGC 作为相关概念或技术标签使用，一级服务使用已确认名称。
- 算力服务聚焦硬件、计算资源与基础运行环境；模型服务聚焦模型部署、推理及训练适配；应用服务聚焦知识、工具与业务流程的组合及系统集成。
- 模型服务中的推理接口提供模型调用能力；应用服务中的系统集成将模型调用、资料处理与任务执行组织成具体应用，按交付重点区分。
- 模型训练与微调中的任务效果验证用于检查目标任务表现；治理服务中的模型安全评测用于识别安全风险，两者分别约定测试目标和指标。
- FDE（Forward Deployed Engineering）用于说明深入实际场景开展工程交付的方式，不作为全部应用工程服务的同义词，也不预设驻场交付。
- RAG 是检索增强生成方法，不作为“知识库”的同义词；工作流采用预设流程，智能体按任务动态选择执行步骤和工具，二者根据场景分别设计或组合。简单知识存储或问答助手不自动称为 RAG 应用或智能体。
- AIGC 用于解释人工智能生成内容的相关能力；多模态内容集成作为跨媒介制作能力，贯穿文字、图像、音频和视频服务。
- 五条服务线可以分别提供或组合交付；治理服务贯穿算力环境、模型、应用及内容生产过程。服务分类是面向官网的组织方案，不宣称属于统一行业标准分类。
- 治理服务分项按用户确认的四个方向组织：渗透测试评估针对组织与环境，模型安全评测针对模型，防护能力建设关注整体防攻击能力，合规评估与改进围绕实际展业地区及业务形态展开。
- 模型安全评测按模型类型与可访问条件选取测试项，不默认所有模型都是大语言模型。提示注入、工具越权等应用层风险，结合具体系统纳入组织与环境评估及防护建设。
- 合规评估以实际展业地区及业务活动为范围；管理标准与风险指南用于辅助组织控制措施，不直接等同于当地法律或监管要求。
- 用户已授权将图像等扩展内容纳入业务介绍。服务介绍、分项描述与交付成果仍为本轮文案，不据此推导定价、技术指标、服务时限或认证承诺。
- 评测交付需注明被测对象与版本、测试场景、方法、覆盖范围及已知局限，便于复现与后续对比。
